# Лабораторная работа №3: Текстурирование


## Цель лабораторной работы
В этой лабораторной работе вам предстоит загрузить изображения из файловой 
системы, создать текстуры из изображений и, используя текстурные координаты
в вершинах, а также сэмплеры, наложить их на рисуемые объекты.

## Условие

Цель работы: загрузить изображения из файловой системы, создать текстуры из изображений и, используя текстурные координаты в вершинах, а также сэмплеры, наложить их на рисуемые объекты.

Выполненный вариант: Вариант 9 (Конус). Выполнены все дополнительные задания.

Требования: необходимо использовать Vulkan, GLFW и ImGUI. Программа должна работать в реальном времени, к элементам пользовательского интерфейса следует добавить выбор текстуры из выпадающего списка, если их будет несколько.

Условие:

• Использовать код предыдущей лабораторной работы, чтобы внести поддержку текстур в качестве альбедо (основного цвета) вместо использования сплошного цвета или цвета для вершин.
• Изображения должны быть загружены из файловой системы. Формат файлов растровой графики может быть любым: PNG, JPEG, GIF, BMP, TIFF, TGA и др. Используйте сторонние библиотеки для загрузки и декодирования изображений.
• Программа должна работать в реальном времени, к элементам пользовательского интерфейса следует добавить выбор текстуры из выпадающего списка, если их будет несколько.
• У вершин, помимо атрибутов позиции и нормали, должны быть текстурные координаты. Для большей части фигур текстурные координаты можно сгенерировать процедурно вместе с позицией и нормалями.
• Для одного из объектов на сцене должно быть реализовано нетривиальное сэмплирование.
• Для контроля использования нетривиального сэмплирования текстуры для объектов следует использовать флаги или параметры в push-константах вместо введения новых данных в структуру свойств моделей в uniform-буфере.
• Используйте один динамический uniform-буфер (массив из структур свойств моделей) вместо множества uniform-буферов для каждой модели. Сдвиг чтения структуры со свойствами модели динамического uniform-буфера должен задаваться в команде привязки наборов дескрипторов к текущему графическому конвейеру.
• Переведите память для вершинных и индексных данных на GPU вместо RAM, по аналогии с копированием текстур в VRAM. Теперь вершинные и индексные буферы должны иметь память в VRAM. Используйте staging-буфер и команды GPU на копирование из staging-буфера.

Оценивание:

• На оценку 3 — базовое задание без выполненных дополнительных заданий.
• На оценку 4 — базовое задание с первыми тремя дополнительными заданиями.
• На оценку 5 — все дополнительные задания.

Базовое задание: для объектов из предыдущей лабораторной работы необходимо наложить только одну текстуру без дополнительных эффектов. Push-константы использовать не нужно; если push-константы всё ещё используются для свойств объекта, необходимо перевести данные на uniform-буферы и наборы дескрипторов. Вершинные и индексные данные модели должны быть в VRAM (GPU). В итоге множество объектов будут использовать один набор дескрипторов, где будут привязаны динамический uniform-буфер и один кортеж изображение-сэмплер.

Дополнительные задания:

1. Загрузить множество разных текстур с возможностью их выбора для каждой модели при помощи элементов интерфейса. Для каждого материала (текстуры) будет свой набор дескрипторов.
2. Реализовать для одного объекта нетривиальное сэмплирование, модуляцию цвета сэмплированного изображения, а также множественное сэмплирование того же изображения разными текстурными координатами. Оно не должно быть статичным, а быть параметризованным от времени. Включение нетривиального сэмплирования в шейдере должно быть реализовано при помощи push-констант.
3. (На оценку 5) Добавить поддержку specular и emissive текстур вместе с альбедо. Specular-текстура диктует, какая часть геометрии должна блестеть, а emissive-текстура суммируется с посчитанным цветом пикселя после Блинн-Фонга, минуя расчёт по Блинн-Фонгу. Должен создаваться эффект, будто объект в некоторых местах светится в темноте. Для specular-текстуры можно использовать online-генератор, а emissive-текстуру можно сгенерировать из шума Перлина. Если для некоторых текстур альбедо отсутствуют текстуры specular и emissive, вместо них используется служебная текстура с одним чёрным пикселем.
