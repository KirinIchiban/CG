# Лабораторная работа №1: Основы 3D-графики[cite: 6]

## Цель лабораторной работы[cite: 6]
В этой лабораторной работе вы познакомитесь с основами 3D-графики: построением простых 3D-объектов, проекцией на 2D-плоскость, а также научитесь работать с матрицами перспективы, ортографической проекции и аффинными преобразованиями[cite: 6].

## Требования[cite: 6]
* Вы должны использовать Vulkan, GLFW и ImGUI[cite: 6]. Стартовый код уже всё это содержит[cite: 6].
* Программа должна работать в реальном времени, с возможностью динамической смены проекции и трансформаций объектов[cite: 6].
* Все объекты должны корректно отрисовываться с учетом проекции и иметь возможность взаимодействия с пользователем[cite: 6].
* **Оценка 3:** Выполнить вариант лабораторной работы без дополнительных заданий[cite: 6].
* **Оценка 4:** Выполнить вариант задания с 5 первыми дополнительными заданиями[cite: 6].
* **Оценка 5:** Выполнить все дополнительные задания[cite: 6].

## Дополнительные задания[cite: 7]
1. Обеспечьте переключение матрицы проекции (ортографическая и перспективная) в интерфейсе[cite: 7].
2. Добавить элементы интерфейса для изменения позиции, поворота и растяжения фигуры[cite: 7].
3. Добавить возможность движения и поворота фигуры по сложной траектории, сделать элемент интерфейса для паузы и воспроизведения "анимации", а также возможность изменять скорость "анимации" и другие параметры траектории (например радиус траектории и др.)[cite: 7].
4. Добавить возможность изменять цвет фигуры с помощью элементов интерфейса (в ImGUI есть ColorEdit для этого)[cite: 7].
5. Назначить процедурно цвета для каждой вершины, например в зависимости от позиции вершин в локальной системе координат фигуры, тогда возможность изменять цвет с помощью элементов интерфейса будет умножать выбранный цвет на цвет вершин[cite: 7].
6. **(На оценку 5)** Подумать, как можно нарисовать больше одного объекта на сцене используя больше одного набора дескрипторов (`VkDescriptorSet`)[cite: 7].
